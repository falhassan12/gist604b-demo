# ArcGIS Spatial Validation Toolbox

## Project Context

The **ArcGIS Spatial Validation Toolbox** is a Python-based ArcGIS Pro toolbox developed to support automated spatial validation of development and **Land Use Permit (LUP)** projects.  
The toolbox is designed for use within **ArcGIS Enterprise environments**, where multiple GIS users operate on a shared enterprise geodatabase and require consistent, repeatable spatial compliance checks.

The system enables planners and GIS analysts to validate proposed development features against configurable spatial rules—such as setbacks, crossings, containment, and infrastructure proximity—without altering existing database structures or introducing new data stores.  
This approach ensures compatibility with enterprise governance policies while improving efficiency and accuracy in spatial review workflows.

---

## Key Constraints

The toolbox was designed under the following operational constraints:

- Enterprise geodatabase schema cannot be modified  
- No deployment of additional databases or external services  
- Must operate within existing ArcGIS Pro installations  
- Validation rules must be configurable without code changes  
- Must support multi-user enterprise workflows (24+ users)

---

## System Architecture

The toolbox follows a modular and rule-driven architecture that separates user interaction, validation logic, and configuration management.  
This design improves maintainability and allows validation rules to evolve independently of the underlying code.

- **Toolbox** (`Toolbox/SpatialValidation.pyt`)  
  Provides the ArcGIS Pro user interface and exposes validation tools.

- **Validation Engine** (`Toolbox/validation_engine.py`)  
  Implements the core spatial validation logic through the `SpatialValidator` class.

- **Rule Configuration** (`Config/rules_config.json`)  
  Defines validation rules using a JSON-based structure.

- **Utility Module** (`Toolbox/utils.py`)  
  Contains helper functions for reporting, summaries, and common operations.

---

## Supported Rule Types

The following spatial validation rule types are supported:

- **MINIMUM_DISTANCE** – Setbacks and feature separations  
- **MAXIMUM_DISTANCE** – Access and proximity requirements  
- **INTERSECTION_ANGLE** – Road intersection geometry validation  
- **CROSSING_ANGLE** – Utility crossing angle validation  
- **CONTAINMENT** – Feature containment within boundaries  
- **ATTRIBUTE_DISTANCE** – Dynamic distance thresholds based on attributes

## Testing

Validation logic and rule behavior are tested using a controlled dataset generated by:

`Toolbox/test_data_generator.py`

This script creates a sample geodatabase with predefined **pass and fail scenarios**, supporting:

- Tool validation  
- Rule verification  
- Regression testing  
- Preparation for AI model training and evaluation
